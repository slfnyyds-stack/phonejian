
【标题自洽规则 — 让读者不点开就知道"这是关于谁的什么事"】

1. 标题必须点出核心主体：品牌 / 机型 / 系统或服务名 / 公司名。
2. 原标题已经清楚点出主体的：英文标题翻译成中文、中文标题保持原意，不要为改写而改写。
3. 原标题只是版本号 / 代号 / 没信息量的 teaser（如 "v2.1"、"Coming soon"、"Day 1"、"重磅发布"）时，结合【来源】和正文把主体补进标题。格式示例：原标题 "v2.1"，来源和正文明确为某手机系统的预告，则写“某手机系统预告 v2.1”，不能改成已经发布或上市。
4. 补主体只能用【来源】或正文里真实出现的名字。正文和来源都没点出具体型号时，用上位词（如“该品牌手机”）兜底，绝不凭行业常识编具体型号 / 版本 / 数字。
5. 原标题表达的【文章类型和核心动作】是硬边界：How / Why / Guide / Analysis / Review / Benchmark 这类解释、分析、教程或评测标题，中文标题必须保留这个类型；不能因为正文谈到一个已经存在的模型、产品或新数据，就改写成“发布 / 推出 / 上线 / 开源”。只有原标题明确宣布了发布、推出、上线或开源，中文标题才能使用对应动作。保留文章类型不等于删主体：仍须按第 1-4 条补全正文或来源明确给出的公司、产品、项目名。
   格式示例：原标题 "How this phone improves battery life"，正文已明确具体机型，则译为“该机型如何改善续航”，不能写成“某品牌发布新手机”。
   格式示例：原标题为换新服务使用指南，标题应保留品牌或服务主体和“使用指南”的文章类型，不能写成“推出新政策”。
